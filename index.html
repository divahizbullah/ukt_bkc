Import dari Excel

Isi nama dojo dan nama pengupload dulu, lalu tarik file Excel (.xlsx, .xls, .csv) ke sini, atau

Baris pertama harus berisi judul kolom: Nama, Dojo (boleh dikosongkan, otomatis memakai dojo yang dipilih di atas), Wilayah, Tempat Lahir, Tanggal Lahir, Tingkat Sekarang, Tingkat Tujuan. Format tanggal: 31-12-2010 (hari-bulan-tahun). Template Excel dari tombol di bawah sudah memakai pilihan (dropdown) untuk Dojo, Tingkat Sekarang, dan Tingkat Tujuan agar tidak salah ketik. Dojo harus sudah terdaftar di menu Administrator; Jika kolom Wilayah kosong, wilayah diisi dari data dojo; Pelatih selalu diisi otomatis dari data dojo. Baris yang kolom Dojo-nya berbeda dengan dojo yang dipilih di atas ditolak. Biaya ujian dan status pembayaran diatur per dojo di menu Administrator. Contoh: Kyu 7 (Putih) ke Kyu 6 (Kuning).

Info ujian

Backup data

Ada dua cara menyimpan backup: unduh langsung ke perangkat (tanpa email), atau kirim lewat email. Backup berisi semua peserta, dojo, info ujian, dan setoran/keuangan.

Pilihan 1: Unduh ke perangkat (tanpa email)

File .json dipakai untuk memulihkan data ke aplikasi ini. File .xlsx berisi data lengkap (peserta, dojo, pengeluaran) untuk dibuka di Excel, tetapi tidak bisa dipulihkan.

Pilihan 2: Kirim lewat email

Tombol ini mengunduh file backup lalu membuka aplikasi email dengan pesan siap kirim. Lampirkan file yang baru diunduh sebelum menekan kirim; halaman ini tidak bisa mengirim email atau melampirkan file otomatis.

Import dojo dari Excel (massal)

Tarik file Excel (.xlsx, .xls, .csv) ke sini, atau

Baris pertama harus berisi judul kolom: Nama Dojo, Wilayah, Nama Pelatih, Kontak, Email Pelatih, Biaya Ujian, Status Pembayaran. Kolom Nama Dojo, Wilayah, dan Nama Pelatih wajib diisi; kolom lain boleh kosong. Status diisi Belum atau Lunas (kosong dianggap Belum).

Pendaftaran dojo

Peserta hanya bisa didaftarkan untuk dojo yang sudah terdaftar di sini. Wilayah dan nama pelatih peserta diambil otomatis dari data dojo. Biaya ujian dan status pembayaran dicatat per dojo di sini; tagihan dojo = jumlah peserta x biaya ujian.

Data & file upload

Riwayat import Excel peserta: siapa yang mengupload, untuk dojo mana, kapan, dan file aslinya. Klik Lihat untuk membuka isi file, atau Unduh untuk menyimpan file aslinya.

Arsip upload belum aktif di database. Jalankan SQL ini di Supabase (SQL Editor), lalu muat ulang halaman. Selama belum dijalankan, riwayat upload hanya tampil di sesi ini. 
create table if not exists bkc_upload (
  id text primary key,
  data jsonb not null,
  created_at timestamptz default now(),
  updated_at timestamptz default now()
);
alter table bkc_upload add column if not exists dojo text generated always as (data->>'dojo') stored;
alter table bkc_upload add column if not exists pengupload text generated always as (data->>'nama') stored;
alter table bkc_upload add column if not exists nama_file text generated always as (data->>'file') stored;
alter table bkc_upload add column if not exists peserta_masuk integer generated always as ((data->>'masuk')::integer) stored;
alter table bkc_upload add column if not exists baris_ditolak integer generated always as ((data->>'ditolak')::integer) stored;
alter table bkc_upload add column if not exists status text generated always as (data->>'status') stored;
alter table bkc_upload enable row level security;
drop policy if exists "upload_insert" on bkc_upload;
drop policy if exists "upload_select" on bkc_upload;
drop policy if exists "upload_update" on bkc_upload;
drop policy if exists "upload_delete" on bkc_upload;
create policy "upload_insert" on bkc_upload for insert to anon, authenticated with check (true);
create policy "upload_select" on bkc_upload for select to authenticated using (true);
create policy "upload_update" on bkc_upload for update to authenticated using (true) with check (true);
create policy "upload_delete" on bkc_upload for delete to authenticated using (true);
grant insert on bkc_upload to anon;
grant select, insert, update, delete on bkc_upload to authenticated;
SQL lengkap semua tabel (peserta, dojo, profil, dll.) ada di file database.sql.
